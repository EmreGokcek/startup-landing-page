# StartupAI — Startup Landing Page

Yapay zeka startup'ı için modern landing page. Tailwind CSS ile yapıldı.

## Canlı Demo
Yakında eklenecek.

## Kullanılan Teknolojiler
- HTML5
- Tailwind CSS v3
- Google Fonts (Inter)
- Git & GitHub

## Proje Yapısı
- index.html — Sayfa içeriği
- input.css — Tailwind giriş dosyası
- output.css — Tailwind çıkış dosyası
- tailwind.config.js — Tailwind konfigürasyonu
- README.md — Proje açıklaması

## Özellikler
- Sticky navbar
- Hero bölümü
- 6 kartlı özellikler grid'i
- 3 planlı fiyatlandırma bölümü
- SSS bölümü
- İletişim formu
- Footer
- Responsive tasarım (mobil, tablet, masaüstü)
- Dark mode

## Kurulum
Projeyi lokalde çalıştırmak için:

1. Repoyu klonla
   git clone https://github.com/EmreGokcek/startup-landing-page.git

2. Klasöre gir
   cd startup-landing-page

3. Bağımlılıkları kur
   npm install

4. Tailwind'i başlat
   npx tailwindcss -i ./input.css -o ./output.css --watch

5. index.html dosyasını Live Server ile aç
